## Prompt

Create one blank wide horizontal game UI button background, aspect ratio 2.7:1, matching the reference's warm tan sandstone slab, beveled golden stone edges, dark brown outer contour, clipped corners, restrained cracks and subtle texture. Front-on flat orthographic UI sprite, no perspective. Large quiet flat tan center for readable text added later. Entire button visible, tightly framed with minimal transparent padding. Genuine transparent background outside the button. No text, symbols, gems, extra objects or shadow extending far outside. Preserve reference style while making the shape wide and short for two buttons side by side in a small game menu.
